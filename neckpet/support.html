FAQ (English)

PiP does not show in Simulator

Some PiP behavior is limited in iOS Simulator. Test PiP on a real iPhone for accurate behavior.

Head tracking is not updating

Make sure Motion & Fitness permission is enabled in iOS Settings for NeckPet. Also verify compatible headphones are connected for headphone mode.

Purchase restore asks for Apple ID password

This is expected behavior from Apple's restore flow on some devices.

常见问题（中文）

为什么模拟器里 PiP 不稳定？

iOS Simulator 对 PiP 支持有限，真实设备上的行为更准确。建议在真机测试。

为什么姿态检测没有变化？

请在系统设置中确认 NeckPet 已开启“运动与健身”权限；耳机模式下请确认连接了兼容耳机。

恢复购买为什么会弹 Apple ID 密码？

这是 Apple 恢复购买流程的常见行为，属于系统层面的正常提示。
